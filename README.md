## Aim

To develop a Python program to evaluate a cricket player's batting, bowling, fielding, and overall all-rounder performance based on the player's statistics.

## Algorithm

1.Algorithm

3.Display the Player Details heading.

4.Get the player's name, runs, balls faced, fours, sixes, wickets, runs conceded, overs bowled, and catches.

5.Calculate the batting strike rate using runs and balls faced.

6.Calculate the bowling economy rate using runs conceded and overs bowled.

7.Compare the runs and strike rate to determine the batting performance.

8.Compare the wickets and economy rate to determine the bowling performance.

9.Check the number of catches to determine the fielding performance.

10.Compare the batting and bowling performance to determine the overall all-rounder category.

11.Display the player's batting, bowling, fielding, and overall performance.

12.Repeat the process for another player using the while True loop.

13.Stop the program.
